# TaskFlow — Productivity Dashboard

A polished, responsive productivity dashboard built from scratch with **HTML, CSS and vanilla JavaScript**.

## ✨ Features

- Modern responsive dashboard UI
- Create, edit, complete and delete tasks
- Search tasks instantly
- Filter by all / active / completed / high priority
- Task priority and due dates
- Live completion statistics
- Productivity analytics
- Weekly progress ring
- Dark / light theme
- LocalStorage persistence
- Mobile sidebar navigation
- Accessible buttons and semantic HTML
- No framework or build step required

## 🛠 Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (ES6+)
- Browser LocalStorage
- Google Fonts (Inter)

## 🚀 Run locally

No installation is required.

1. Download or clone this repository.
2. Open `index.html` in your browser.

For the best development experience, use VS Code with the **Live Server** extension.
